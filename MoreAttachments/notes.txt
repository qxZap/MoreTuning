Items_AttachmentPart is keyed by row name, not position
-------------------------------------------------------
Rows have no numeric id; the DataTable row name is the key, and that is what a
save stores. That is why the game can add attachments in an update without
repainting everyone's vehicles.

So removing or renaming a row is the breaking change -- it takes that part off
every vehicle wearing it. Adding is free. Reordering is cosmetic.

Checked across every commit that touched the table: no row has ever been removed
or renamed here, and the 0.7.19 migration added 46 and dropped none. The one
exception is Attachment_qxWinch, the winch test row, which shipped for a while
and was then deleted.
