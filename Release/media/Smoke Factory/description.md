# Smoke Factory

## Short description

Tyre smoke that lasts longer, gets bigger and rises into the air, for burnouts and drifts that fill the street.

## Long description

Smoke Factory changes the game's own tyre smoke. Every vehicle gets it, nothing to fit or tune.

### What you get

- Smoke that hangs around four times longer.
- Puffs half again as big.
- Smoke that rises instead of hugging the ground.
- Smoke that stays where you slid instead of chasing the car.
- On the game's Low effects setting the smoke stays close to vanilla, to spare your frame rate.

### What you need

- Plugin Loader (its own download).

### Install

1. In Steam, right-click Motor Town > Manage > Browse local files.
2. Drag the MotorTown folder from this download into that window and let it merge.

Settings are in MotorTown\Binaries\Win64\plugins\smoke_factory.ini, created on first launch, under [Smoke]: LifetimeScale (4), SizeScale (1.5), RiseSpeed (40), DragScale (0.3), InheritScale (0.3), and LowEffects=1 to keep the smoke near vanilla whatever your settings. Restart the game after a change. Disabled=1 under [General] turns the plugin off.

### Multiplayer

The smoke is drawn on your own screen, so you see it on every car, yours and other players', on any server.
