# Wheel Size Unlimited

## Short description

Wheel size from 0.1 to 2.0 and wheel width from 0.1 to 1.7, right in the garage's Tuning screen, and any wheel on any vehicle.

## Long description

Wheel Size Unlimited is now a plugin. The old version shipped copies of every wheel at fixed sizes (-50% to +100%). This one uses the game's own wheel tuning and just widens it, so there are no duplicate wheels in the shop, and it works with whatever wheels you have installed.

### What you get

- Wheel size from 0.1 to 2.0 per axle, instead of the game's 0.80 - 1.20.
- Wheel width from 0.1 to 1.7 per axle. The game supports width but never shows it on the Tuning screen; the plugin adds a width line under each size line.
- Steps of 0.01, as in vanilla.
- Any wheel on any vehicle: every wheel, from the game or from a wheel mod, can be fitted to every vehicle, dually and rear axles included. The shop a wheel is sold in stays the same.
- Works with Maja's Mo Wheel Works: her meshes stay as they are.
- Boats are left alone: no wheel size on propellers.

### What you need

- Plugin Loader (its own download).
- Nothing else. Maja's Wheel Works is no longer required.

### Install

1. In Steam, right-click Motor Town > Manage > Browse local files.
2. Drag the MotorTown folder from this download into that window and let it merge.

Settings are in MotorTown\Binaries\Win64\plugins\wheel_size_unlimited.ini, created on first launch: Min / Max for size, WidthMin / WidthMax for width, and Step. Disabled=1 under [General] turns the plugin off.

Upgrading from the old version: delete the old Wheel Size Unlimited pak (zzzProxyWheelSizeUnlimited_P.pak) and its Carbon and ProxyTech Wheels variants from your Paks folder. The plugin replaces all of them.

### Multiplayer

Size and width work in single player and on a server you host. On someone else's server the server decides, and a vanilla server keeps 0.80 - 1.20.
