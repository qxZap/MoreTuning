# Crisp Sky

## Short description

A real night sky for Motor Town: thousands of real stars and the Milky Way, darker nights, and a softer, more photographic day. One pak, nothing else needed.

## Long description

Crisp Sky changes how the sky and the light look in Motor Town.

- A real night sky: about 9,000 catalogued stars and the Milky Way, turning with the sun. They come out at dusk.
- Darker nights: night no longer looks like dim daylight. Headlights and street lights carry the scene.
- A more photographic day: a softer film look, a touch warm, with light haze in the distance.

Install: drag the MotorTown folder from this download onto the game folder (Steam > Manage > Browse local files). To remove it, delete MotorTown\Content\Paks\CrispSky_P.pak.

Just one pak: no plugin or loader needed. Source and build steps: github.com/qxZap/CrispSky
