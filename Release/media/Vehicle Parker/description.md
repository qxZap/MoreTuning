# Vehicle Parker

## Short description

One key to put every vehicle you own back in your list. Press Ctrl+F10 and the map is clear; your camper stays where it is.

## Long description

Vehicles you leave around the map stay out until you despawn them one by one in the vehicle list. Vehicle Parker does it in one go.

### What you get

- Ctrl+F10 sends every vehicle you own back to your vehicle list, the same as pressing Despawn on each one.
- Nothing is sold or deleted: spawn them again from the list whenever you want.
- Campers stay out, so your base on wheels stays where you parked it.

### What you need

- Plugin Loader (its own download).

### Install

1. In Steam, right-click Motor Town > Manage > Browse local files.
2. Drag the MotorTown folder from this download into that window and let it merge.

Settings are in MotorTown\Binaries\Win64\plugins\vehicle_parker.ini, created on first launch. Disabled=1 under [General] turns the plugin off.

### Good to know

Vehicle Parker used to be part of Capitalist Economy. It is its own plugin now, so it works with or without it.
